# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

We are committed to providing a welcoming and inclusive environment. Examples of unacceptable behavior include harassment, insulting comments, and personal attacks.

Report unacceptable behavior by opening a private security advisory or contacting the maintainer directly through GitHub.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
